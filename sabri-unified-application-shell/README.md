### Conditional privacy and shell behavior

Sensitive clinical, case/appeal, checkout/billing, finance-admin/API, media-admin/API, Insights/analytics, and language/localization administration/API routes are added to File 20's bounded privacy policy so local Recent/Resume, Smart Navigation and predictive prefetch cannot treat them as ordinary public destinations.

`/media/d/{grant}` is deliberately **not** made a File-20 private/no-store route because CF-04 owns token delivery, range and cache semantics. It receives Minimal/no visual Future Shell presentation instead, so File 20 contributes no Recent/Prefetch client state while native delivery/cache authority remains intact.

Verified user transfer remains a File 17 workflow with CF-04 secure processing after activation and the approved per-file limit remains **1 GB**. Eligible download remains native-owner/File-24/CF-04 territory; File 20 supplies only the UI entry.
